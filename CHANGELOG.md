# Changelog

本文件记录 **WasmNest 平台仓**（双端宿主 + 端内 SDK + 构建 / 发布工具）的版本变更，中英双语置于同一文件（中文在前，English 在后）。各 wasm 应用的业务变更见应用仓对应应用的 `CHANGELOG.md`。

- 版本真源：`package.json` 的 `version`，与 `release-manifest.json` 的 `product`、双端 `tauri.conf.json` 一致。
- 发布 tag：`v<X.Y.Z>`。
- 发布说明：发布工作流按 `product` 提取本文件对应版本段落（含中英双语）写入 GitHub Release；段落缺失即发布失败。
- 对比口径：本版相对上一版 `v0.0.1`（2026-10-28）；本版 `v0.0.2`（2026-11-19）。
- 结构参考 [Keep a Changelog 中文](https://keepachangelog.com/zh-CN/1.1.0/) / [Keep a Changelog EN](https://keepachangelog.com/en/1.1.0/)，版本号遵循 [Semantic Versioning](https://semver.org/)。

## [0.0.2] - 2026-11-19

### 中文

#### 新增

- 运行指标：双端新增宿主进程维度指标（WebView PSS / RSS / CPU 与 wasm 线性内存分账），只读监控面可按 `present` 分支展示。
- 剪贴板能力域：新增 `clipboard:read` / `clipboard:write` 分域授权，门禁 fail-closed（未声明即拒）。
- 应用更新链路：设置页补齐检查更新入口，SDK 提供 `AppUpdateSection`，根构建脚本生成 `latest.json`。
- 应用生命周期：卸载可选保留数据（`keepData`），全新安装可恢复（`restoreData`）；应用管理页常显当前版本号。
- SDK：新增 Go 后端 SDK 壳 v0；插件类型统一为 `backend` / `frontend` / `full` 三形态。
- 发布线：新增 Android arm64 APK（移动插件现场构建后打进 assets，独立 keystore 签名，空包即判失败）。
- 工具：新增 worktree 共用 target 桶脚本（`pnpm run target:worktrees`），避免每棵 worktree 各自生成整套 Rust 构建产物。
- 文档：新增 [NAT 穿透](docs/nat-traversal.md)、[target 治理](docs/target-governance.md) 与 ADR 0058–0061（信任边界、主题预设、快捷键、WIT 按包拆分）。

#### 变更

- 契约升级：`wasmnest:plugin` 由 `0.0.1` 升至 `0.1.0`，WIT 改为按包版本化（[ADR 0061](docs/adr/0061-wit-package-split.md)）；`release-manifest.json` 成为跨仓版本唯一表达，钉 `lib-v0.1.0` / `apps-v0.0.3` 并更新 WIT 指纹。
- 双端外观：品牌标记重绘并更新图标与双语 README；皮肤并入主题预设，glass 合并为整屏玻璃材质（[ADR 0059](docs/adr/0059-theme-presets-absorb-skins-and-glass-boundary.md)）。
- 桌面多任务卡改为展示真实实例页面，新增悬浮导航磁贴与快捷卡片轮播。
- 状态栏第三方扩展渲染隔离，注册 `id` / `label` 增加非空校验，异常不再冒泡到全局错误弹窗。
- 构建 / CI：Windows 发布改用现场构建的 Rust 响应文件包装器与短 `CARGO_TARGET_DIR`；重发同版本时同步清理陈旧资产与 Release 说明。

#### 修复

- Windows 发布规避 rustc 命令行超 `CreateProcess` 上限（os error 206）及产物落错目录（os error 3）。
- 桌面退出确认修复，接入有界优雅关闭并回收 mDNS 广播句柄；移除玻璃主题每帧整屏重绘（实测 62fps → 11fps）。
- 移动端启动失败原因改为可读正文（不再显示 `[object Object]`）；SAF 中转复制补总超时，避免 provider 不回调时 async 任务永久挂起。
- 发布说明不再无条件断言「Authenticode 已签名」，改由签名状态段落说明。

#### 安全

- 双端 CSP 移除 `'unsafe-eval'`；i18n 消息改为构建期预编译，不再依赖运行时编译。
- 新增宿主命令身份门与调用方解析（[ADR 0058](docs/adr/0058-frontend-trust-boundary-and-command-surface-threat-model.md)），fail-closed 覆盖退出 / 更新 / 日志 / `save_app_settings` 等宿主职权面。
- 链路加密新增 WS 帧级加密与移动端 per-app HTTP 信封，`required` 加密不被本端自愿降级；宿主职权出站按调用方身份记账。

### English

#### Added

- Runtime metrics: both hosts now expose host-process dimensions (WebView PSS / RSS / CPU accounted separately from wasm linear memory), which the read-only monitoring surface can render by `present`.
- Clipboard capability domain: `clipboard:read` and `clipboard:write` are authorized separately and fail closed (denied when undeclared).
- App update flow: a check-for-updates entry in settings, `AppUpdateSection` in the SDK, and `latest.json` generated by the root build script.
- App lifecycle: uninstall can keep data (`keepData`) and a fresh install can restore it (`restoreData`); the app management page always shows the current version.
- SDK: a v0 Go backend SDK shell; plugin types unified into the language-agnostic forms `backend` / `frontend` / `full`.
- Release pipeline: Android arm64 APK added (mobile plugins are built during the job and packaged into assets, signed with a dedicated keystore, and an empty package is a hard failure).
- Tooling: a shared target bucket for worktrees (`pnpm run target:worktrees`), so each worktree no longer grows its own full Rust build tree.
- Docs: [NAT traversal](docs/nat-traversal.md), [target governance](docs/target-governance.md), and ADRs 0058–0061 (trust boundary, theme presets, shortcuts, WIT package split).

#### Changed

- Contract upgrade: `wasmnest:plugin` moved from `0.0.1` to `0.1.0` and WIT is now versioned per package ([ADR 0061](docs/adr/0061-wit-package-split.md)); `release-manifest.json` is the single cross-repository version expression, pinned to `lib-v0.1.0` / `apps-v0.0.3` with an updated WIT fingerprint.
- Both hosts restyled: redrawn brand mark with refreshed icons and bilingual READMEs; skins folded into theme presets, and glass merged into a full-screen glass material ([ADR 0059](docs/adr/0059-theme-presets-absorb-skins-and-glass-boundary.md)).
- Desktop task cards now show the real instance page; added a floating navigation tile and a quick-card carousel.
- Third-party status-bar extensions render in isolation, registration `id` / `label` are validated as non-empty, and render errors no longer bubble up to the global error dialog.
- Build / CI: Windows releases use an on-site-built Rust response-file wrapper and a short `CARGO_TARGET_DIR`; re-releases now clean stale assets and update the release notes together.

#### Fixed

- Windows release avoids exceeding the rustc command-line `CreateProcess` limit (os error 206) and artifacts landing in the wrong directory (os error 3).
- Desktop close confirmation now works, with bounded graceful shutdown and mDNS advertiser cleanup; removed the glass-theme full-screen repaint on every frame (measured 62fps → 11fps).
- Mobile startup failures now surface readable text instead of `[object Object]`; SAF relay copies have an overall timeout so a non-responding provider cannot hang the async task forever.
- Release notes no longer unconditionally claim "Authenticode signed"; signing status is described in its own section.

#### Security

- Both hosts drop `'unsafe-eval'` from CSP; i18n messages are precompiled at build time and no longer require runtime compilation.
- Added a host-command identity gate and caller resolution ([ADR 0058](docs/adr/0058-frontend-trust-boundary-and-command-surface-threat-model.md)), fail-closed across host-privileged surfaces such as exit, update, logs, and `save_app_settings`.
- Link encryption adds WS frame-level encryption and a mobile per-app HTTP envelope; `required` encryption can no longer be downgraded by local opt-outs, and host-privileged egress is accounted by caller identity.
