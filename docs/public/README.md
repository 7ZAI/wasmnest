# Public —— 四仓共享的通用规范（真源）

> **本目录是 WasmNest 四仓（平台 / 能力 / 应用 / 跨端测试）共享的通用规范真源。**
> 存放**跨仓通用**的开发规范：git 提交、代码注释与命名、测试与验证、版本号管理、issue 管理。各仓 AGENTS.md 一律引用本目录，**不在各自仓内复制通用规范内容**（防多源漂移）；仓特有的规范（命令、路由、锁清单、目录导览…）仍留在各仓 AGENTS.md 与各自的 docs/。

## 1. 引用方式

| 仓 | 引用路径 |
| --- | --- |
| 平台仓 `wasmnest` | `docs/public/<文件>`（AGENTS.md 见 `docs/public/`） |
| 能力仓 `../wasmnest-lib` | `../wasmnest/docs/public/<文件>` |
| 应用仓 `../wasmnest-apps` | `../wasmnest/docs/public/<文件>` |
| 测试仓 `../wasmnest-test` | `../wasmnest/docs/public/<文件>` |

## 2. 文档清单

| 文件 | 规范 | 适用对象 |
| --- | --- | --- |
| `git.md` | git 提交规范：commit 格式 / 禁止 AI 标记 / --force 禁令 / 开工自检 / 只提交源码 / 文件回滚 / 四仓 tag 与跨仓提交顺序 | 四仓全部提交 |
| `commenting.md` | 代码注释与命名：解释为什么 / 中文 / 禁票号引用 / 同步修正注释 / 命名规则 | 四仓全部代码 |
| `testing.md` | 测试与验证：单元测试形态 / 禁止交付类型 / 临时目录 / 锁纪律（Seam 3）/ 验证底线 | 四仓全部测试与交付 |
| `versioning.md` | 版本号管理最佳实践：**只有发布版本时才设置版本号，dev 日常不 bump**；bump 号段判据 / 各仓设置点 / 发布动作清单 | 四仓全部发布与开发 |
| `issues.md` | issue 管理规范：GitHub Issues = 跨会话存续 backlog 真源；三层分工 / 落仓规则 / 模板与标签 / 关门纪律 / agent 约定 | 四仓全部存续任务与缺陷 |

## 3. 维护规则

- **改通用规范来这里改**（单一真源）；各仓 AGENTS.md 只保留「指针 + 仓特有增量」。
- 本目录与各仓 AGENTS.md 的硬约束**同级别**（「必须 / 禁止」字样等效，冲突裁决按各仓 AGENTS.md 的优先级表）。
- 新增通用规范文件：先问「这个规范四仓都适用吗？仓里有第二个消费者吗？」——只有跨仓通用才放这里；平台特有的（如权限闸门 / WIT 链 / 前端零资源访问）留在平台仓 `docs/` 对应主题文档。
- 修改受引用文件时，同步核对四仓 AGENTS.md 的指针无需改动（路径不变即可）。
